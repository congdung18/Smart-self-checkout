# Introduction
Have you ever feel exhausted having to wait in lines at malls for accountants to check your stuff.
If yes, we introduce Smart self-checkout system, an open source project allowing you to scan the barcode independently and checkout early.

# About the authors
This project is developed by a group of 4 students in VNU-HCMUS for the subject called Intro to Software Engineering. We aim to produce an open source where people can collaborate, solving the issue of clients have to wait in lines and allowing them to pay by themselves.

# About the product 
This project will aim to free customers from lines of payment by:
  - scanning barcodes by yourself
  - verify the product value 
  - full payment flow

However, there are several issues, such as:
  - costumers can steal the products
  - there is no final verification step
